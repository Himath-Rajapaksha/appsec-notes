# Labs

Deliberate-practice writeups, one file per lab, in my own words.

Format (see `templates/lab.md`):

- **Target** — what the lab is
- **Goal** — the objective, stated before starting
- **What I tried** — including the dead ends; they are the point
- **What worked** — payload or chain, with the reasoning
- **Root cause** — the underlying class of bug
- **Transferable** — how I would look for this on a real target
